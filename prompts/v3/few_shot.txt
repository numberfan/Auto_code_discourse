## KEY CONTRASTS

**Hard stop vs trigger**
- "Yes." / "No." / "Smaller." / "Very small." → hard stop, no code
- "(Inaudible)" → hard stop, no code
- "They didn't have an iPad." (statement) → no trigger, no code
- "Yes, and why do you think so?" → has question, proceed to code

**say_more vs press_for_reasoning**
- "Was there a cover?" → say_more (factual detail)
- "Who are the they?" → say_more (clarification)
- "What should they have done instead?" → say_more (asks for PROPOSAL)
- "What do you think about X?" → say_more (solicits new opinion)
- "Because what?" → say_more (completing unfinished sentence)
- "Why do you think that?" → press (asks WHY a claim is true)
- "What's your evidence?" → press (evidence for claim)
- "What difference does that make?" → press (logical consequence)
- "Why is that important?" → press (causal significance)

**revoice vs say_more**
- "So you're saying X?" (rephrasing IS the purpose) → revoice
- "That's the reason? They're old." (echoing claim back) → revoice
- "OK, and then what?" (echo + new question) → say_more

**challenge vs press**
- "Well, remember, they're from 50 years ago." (provides counter-info) → challenge
- "Why do you think they're old?" (asks for reasoning) → press

**add_on: must contain question/invitation**
- "Anyone else? Any other ideas?" (question) → add_on ✓
- "Do you remember where they studied?" (question) → add_on ✓
- "They didn't have an iPad." (statement only) → no code ✗
- "Very small." (echo only) → no code ✗
